# ZotLink Roadmap

## Future Formal Release Codename

- Prefer using a concrete codename for a later formal major release, ideally `1.0.0`.
- Planned codename: `Yuan'ge`（元歌）.
- Meaning: ZotLink's multi-collection workflow is centered on one real PDF body and multiple shortcut mirrors. When the user changes the primary collection, the real file and shortcut mirrors can swap roles, similar to the "body / clone position swap" idea associated with Yuan'ge（元歌）or Kongkong'er（空空儿）in Chinese popular culture.
- README direction for the formal release: in the "Multi-Collection Shortcut Mirrors 多重 Collection 与快捷方式分身" section, explain the model more vividly as "one body, multiple clones, and position swapping between the real file and shortcut mirrors" while keeping the technical explanation clear for non-Chinese readers.

## 正式版本代号备忘

- 后续正式大版本最好使用一个具体版本代号，理想节点是 `1.0.0`。
- 计划代号：`Yuan'ge`（元歌）。
- 含义：ZotLink 的多重 collection 工作流本质上是一份真实 PDF 本体，加上多个快捷方式分身。当用户切换主 collection 时，真实文件和快捷方式分身可以换位，类似“元歌”或“空空儿”的本体 / 分身换位意象。
- 正式版 README 表述方向：在 `Multi-Collection Shortcut Mirrors 多重 Collection 与快捷方式分身` 部分，可以直接加入“本体、分身、换位”的说明，让用户更容易理解 ZotLink 为什么用 `.lnk` 分身而不是硬链接，同时保持技术说明对不了解该典故的读者也清楚。
